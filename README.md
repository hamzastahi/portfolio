# Hamza STAHI — DevOps & Cloud Portfolio

Static bilingual portfolio for GitHub Pages.

## Pages
- `index.html` — English
- `fr/index.html` — Français

## Design guarantees
- FR/EN switch keeps the current language visibly active.
- Dark/light toggle stays directly beside the language switch on desktop and mobile.
- Skills, projects and certifications all contain visible icons. External brand/badge images have an in-page fallback so a failed CDN image never leaves an empty tile.
- No CV/PDF is published in this repository.

## Contact form
Replace `YOUR_FORM_ID` in both HTML files with your Formspree form ID.

## GitHub Pages
Publish from `main` / repository root. `.nojekyll` is included.
